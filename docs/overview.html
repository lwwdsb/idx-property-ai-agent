Design principles

The LLM lives at the edges

Routing, SQL, price checks and the send gate are deterministic code. The model is used only where it is irreplaceable: understanding vague phrasing and wording an answer.

The model never authors facts

Prices and addresses are rendered from database rows. A runtime grounding gate strips any listing id the model did not actually retrieve.

Robustness has a fixed order

Never send a wrong outbound message > never be confidently wrong > always stay responsive. A machine-checkable tie-breaker when goals conflict.

Measured, not asserted

Every capability has a labelled eval set and a one-command suite, so a regression shows up as a number rather than a surprise.
